# Курс валют by kolobas58

Бат и доллар всегда на виду, своё «избранное», СНГ и весь мир с поиском — как страница [kolobas58.club/rates](https://kolobas58.club/rates), только приложением.

**Windows · Linux · Android** — скачать в [Releases](../../releases/latest).

- курс из 6 независимых источников (kolobas58.club, ExchangeRate-API, Currency API, FloatRates, ЕЦБ, ЦБ РФ) — опрашиваются параллельно,
  по каждой валюте берётся медиана; источник, который застрял на старых данных, отбрасывается; проверка раз в 5 минут
  и при каждом возвращении в приложение; без интернета — последний сохранённый курс;
- считается от введённой суммы, переключение валют не копит ошибку округления;
- ★ — валюта встаёт наверх, к основным (до 8);
- основные валюты (по умолчанию доллар и бат) меняются в «Остальном мире» → «Основные»;
- на Windows и Linux — окно без системной рамки, своя полоска заголовка;
- светлая, тёмная или как в системе.

Сборка: GitHub Actions (`.github/workflows/build.yml`), Flutter 3.24. Платформенные папки генерирует `tool/prepare.sh`.
